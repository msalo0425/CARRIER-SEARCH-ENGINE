Drop your hero videos here.

The hero will cycle through them automatically — name them like this:

  hero-1.mp4
  hero-2.mp4
  hero-3.mp4
  hero-4.mp4
  hero-5.mp4

You can add as few as one (just hero-1.mp4) or as many as you like.
The site auto-detects which files exist, so you don't need all five.

Optional:
  hero-poster.jpg     - static fallback image shown while videos load
  trucks-highway.mp4  - legacy single-file fallback (still works if present)

Tips for the videos:
  - 1920x1080 (1080p), H.264 MP4
  - 8-20 seconds each (they auto-advance to the next when one ends)
  - Mute the audio - it gets stripped anyway and just bloats the file
  - Aim for ~3-5 MB each so the page loads fast on mobile

You can delete this file once your videos are in place.
